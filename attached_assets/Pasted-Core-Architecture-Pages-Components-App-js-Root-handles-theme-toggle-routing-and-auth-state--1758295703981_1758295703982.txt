2. Firebase Setup

Authentication

Enable Google & GitHub OAuth

Store minimal user info (UID, displayName, photoURL)

Firestore Collections

games – stores live and completed games:

{
  "fen": "current FEN",
  "moves": ["e4", "e5", ...],
  "players": { "white": uid, "black": uid | 'bot' },
  "status": "active/completed",
  "winner": "white/black/draw",
  "duration": 120, // seconds
  "difficulty": "easy/medium/hard",
  "createdAt": timestamp
}


users (optional) – stats per user, like total wins/losses

3. Multiplayer Logic

Game creation

When a player joins, check for open games:

Assign as white if empty, else black

If no available game, create new

Move sync

Use Firestore onSnapshot for real-time updates

Validate moves with chess.js before writing

Bot integration

If playing solo, bot makes move after player

Implement difficulty levels:

Easy: random legal move

Medium: prefer captures/checks, some randomness

Hard: prioritize captures, checks, and center control

4. Game Tracking & History
